# Contributing

## Pull requests

This repository isn't accepting pull requests at this time; one that is opened is closed
automatically. Please open an issue instead.

## Issues

Issues are welcome. Open one on
[github.com/morpho-org/morpho-bots/issues](https://github.com/morpho-org/morpho-bots/issues) for a
bug, a question about running a bot, or a proposed change. Include the bot, the release tag you
are running (`git describe --tags`, or the image or npm version), and enough of the log for the
behavior to be reproduced.

## Security

For a vulnerability in one of these bots, open an issue that says a private report is needed
without including the details, and a maintainer will follow up with a private channel.
